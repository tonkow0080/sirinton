# ต้นแบบระบบอุทยานสิ่งแวดล้อมนานาชาติสิรินธร

เว็บไซต์ตัวอย่างสำหรับนำเสนอแนวคิดระบบสมาชิกและการจองคิวเข้าอุทยาน พร้อมหน้าผู้ดูแลที่จัดการสถานที่ กิจกรรม และสื่อการเรียนรู้ ข้อมูลสมาชิกและรายการจองเก็บในฐานข้อมูล SQLite ของโปรเจกต์

> ต้นแบบนี้สาธิตขั้นตอนการใช้งาน ไม่ได้เชื่อมกับระบบจองหรือความจุจริงของอุทยาน ควรตรวจสอบเวลาเปิดและเงื่อนไขการเข้าชมกับอุทยานก่อนเดินทางจริง

## เปิดใช้งาน

ต้องติดตั้ง Node.js 22.13 ขึ้นไป จากโฟลเดอร์ `sirindhorn-park` เปิด Terminal แล้วรัน:

```powershell
npm start
```

จากนั้นเปิดเว็บที่ `http://localhost:3000` ระบบสร้างฐานข้อมูลและข้อมูลตัวอย่างให้เมื่อเริ่มครั้งแรก

## บัญชีตัวอย่าง

สำหรับใช้งานในเครื่อง:

- ผู้ดูแล: `admin@siep.local`
- รหัสผ่าน: `SiepAdmin2026!`

ผู้เข้าชมสมัครสมาชิกได้จากหน้า **เข้าสู่ระบบ / สมัครสมาชิก** โดยใช้ชื่อ อีเมล และรหัสผ่าน เบอร์โทรศัพท์เป็นข้อมูลไม่บังคับ

## ความสามารถในต้นแบบ

- ผู้เข้าชมสมัครสมาชิก เข้าสู่ระบบ และออกจากระบบได้
- สมาชิกเลือกวันเข้าชม ระบุจำนวนผู้เข้าชมได้ 1–20 คนต่อรายการ และรับหมายเลขคิวกับรหัสจอง
- สมาชิกดูประวัติและยกเลิกรายการจองได้
- ผู้ดูแลดูภาพรวม สมาชิก และจำนวนการจองของวันปัจจุบันได้
- ผู้ดูแลเพิ่ม แก้ไข ลบ และเผยแพร่ข้อมูลสถานที่ กิจกรรม และสื่อการเรียนรู้
- ผู้ดูแลอัปโหลดภาพ JPG, PNG หรือ WebP ขนาดไม่เกิน 5 MB และยืนยันหรือยกเลิกรายการจองได้
- ฐานข้อมูลเก็บบัญชีผู้ใช้ รหัสผ่านแบบแฮช เซสชัน รายการจอง สถานที่ และข้อมูลเนื้อหาของเว็บไซต์

หน้าใช้งานหลัก:

- `/` เว็บไซต์อุทยาน
- `/login.html` เข้าสู่ระบบและสมัครสมาชิก
- `/booking.html` จองคิวเข้าอุทยาน
- `/account.html` บัญชีและรายการจองของสมาชิก
- `/admin.html` หน้าหลักและเครื่องมือผู้ดูแล

## ข้อมูลผู้ดูแลเมื่อขึ้นโฮสต์

ในโหมดพัฒนา ระบบสร้างบัญชีสาธิตด้านบนให้อัตโนมัติ หากนำไปโฮสต์ ให้ตั้ง `NODE_ENV=production`, `ADMIN_EMAIL` และ `ADMIN_PASSWORD` ก่อนเริ่มครั้งแรก เพื่อสร้างบัญชีผู้ดูแลของคุณเอง ระบบจะไม่สร้างรหัสผ่านสาธิตในโหมด production

ควรใช้ HTTPS และพื้นที่จัดเก็บถาวรสำหรับโฟลเดอร์ `data/` เพื่อเก็บฐานข้อมูลและภาพที่อัปโหลดข้ามการเริ่มระบบใหม่ หากโฮสต์ลบไฟล์ในโฟลเดอร์นี้ ข้อมูลสมาชิกและรายการจองจะหายไป

## โครงสร้างข้อมูล

- `users` — บัญชีสมาชิกและบทบาทผู้ดูแล
- `sessions` — เซสชันเข้าสู่ระบบที่หมดอายุอัตโนมัติ
- `bookings` — วันเข้าชม หมายเลขคิว จำนวนผู้เข้าชม และสถานะ
- `locations` — สถานที่เรียนรู้ที่จัดการจากหน้าแอดมิน
- `content` — กิจกรรมและสื่อการเรียนรู้ที่แสดงในหน้าเว็บไซต์
- `queue_tickets` — คิวกิจกรรมเดิมของต้นแบบ

## หมายเหตุ

โฟลเดอร์ `public/` เก็บหน้าเว็บ สไตล์ สคริปต์ และภาพประกอบ ส่วน `lib/database.js` สร้างตารางและเติมข้อมูลตัวอย่างอัตโนมัติเมื่อเริ่มโปรแกรม ไฟล์ `../index.html` เป็นภาพตัวอย่างแบบเปิดดูอย่างเดียว; ระบบสมัครสมาชิก จองคิว และผู้ดูแลต้องเปิดผ่านเซิร์ฟเวอร์ด้วย `npm start`
